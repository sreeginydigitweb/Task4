# capability

What this project is able to do, stated plainly, and what it is not able to do.

A capability note is written when a feature becomes real, not when it is
planned. It records the behaviour that exists, the data behind it, and the
limits a reader would otherwise have to discover for themselves.

For Task 4 the honest capability statement is narrow: the application reads
product identity and Amazon search-engine keyword text from the `ledsone`
database and shows them in one HTML table. It does not classify keywords,
because `ledsone` does not classify them.
